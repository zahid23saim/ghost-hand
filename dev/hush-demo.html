Reduced motion is off on this device. When it is on, Hush stops bobbing, rippling, spinning and drifting. Only the blink stays, and goodbye becomes a soft fade.

Try it from your system settings, or in Chrome DevTools under Rendering, "Emulate CSS media feature prefers-reduced-motion". Every expression call returns a promise: await hush.setExpression("delighted") resolves once the spin is over.
